Project: Marg
Category: Coding & developer tools
Summary: Point Marg at any repository and it explores the code with read-only tools, then writes a grounded onboarding guide (ONBOARDING.md) with an architecture diagram, a walkthrough of one real flow, starter tasks and gotchas. Every file:line citation is checked against the files the agent actually read.
Author: Mohnish Rawat (GitHub: mqhnish)
Repository: https://github.com/mqhnish/marg
Licence: MIT

BharatCode API usage
- Base URL: https://bharatcode.ai/api/model/v1
- Default model: qwen-3.8-27b (override with --model or MARG_MODEL)
- Endpoints: POST /responses with function tools (default), POST /chat/completions with tools (--api chat)
- Requests are stateless with store=false; Marg replays function_call and function_call_output items each step
- Retries 429/5xx with backoff (BharatCode returns 503 when the model is busy); continues answers cut off at the output limit
- Auth: Authorization: Bearer $BHARATCODE_API_KEY, read from the environment only, never written to disk

Where it is called
- marg/llm.py      HTTP client for both endpoints, retries, response normalisation
- marg/agent.py    explore-then-write agent loop
- marg/tools.py    the read-only tools exposed to the model (list_dir, read_file, search)
- marg/prompts.py  system prompts
